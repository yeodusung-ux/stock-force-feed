# English Buddy

일기 · 상황 설명 · 주제를 입력하면, **그 내용에 대해서만** 최대한 다양한 각도로 질문하며
영어 대화를 이어가는 학습 앱입니다.

## 무엇을 하는가

1. 한국어든 영어든 원하는 내용을 씁니다. (오늘의 일기 / 상황 설명 / 주제 중 선택)
2. 앱이 그 글을 읽고 **12~15개의 질문을 서로 다른 각도로** 만들어 줍니다.
   사실 · 묘사 · 감정 · 이유 · 의견 · 비교 · 가정 · 과거 경험 · 앞으로 · 상대 입장 ·
   문화 비교 · 표현 확장 · 역할극 · 요약 도전 — 14가지 각도를 돌아가며 사용하고,
   이미 물어본 질문은 다시 묻지 않습니다.
3. 답을 하면 매 턴마다
   - 내용에 대한 자연스러운 영어 리액션 (+ 한국어 번역)
   - 틀린 부분 교정 (진짜 틀린 것만, 없으면 지적하지 않음)
   - 더 자연스러운 표현 1~3개
   - 답변에서 파생된 **새로운 질문 2~4개**
   를 돌려줍니다. 막히면 한국어로 답해도 되고, 그러면 "영어로는 이렇게" 를 알려줍니다.
4. **복습 노트** 버튼을 누르면 그날 대화의 실수 · 표현 · 다시 답해 볼 질문을 정리해 줍니다.

레벨(초급/중급/고급)에 따라 질문 길이, 문법 범위, 한국어 병기 비중이 달라집니다.

## 실행 방법

```bash
pip install -r requirements.txt
export ANTHROPIC_API_KEY=sk-ant-...        # https://console.anthropic.com 에서 발급
python server.py                            # http://localhost:8000
```

환경변수로 조절할 수 있는 것:

| 변수 | 기본값 | 설명 |
|---|---|---|
| `ANTHROPIC_API_KEY` | (필수) | Claude API 키 |
| `ENGLISH_BUDDY_MODEL` | `claude-opus-5` | 모델 교체 (`claude-sonnet-5`, `claude-haiku-4-5` 등) |
| `PORT` | `8000` | 서버 포트 |
| `ENGLISH_BUDDY_FALLBACKS` | `1` | 서버사이드 폴백 비활성화하려면 `0` |

API 키 없이 배선만 확인하려면:

```bash
python smoke_test.py
```

## 구조

```
server.py            파이썬 표준 라이브러리 HTTP 서버 + Claude 호출 (프레임워크 의존성 없음)
  /api/questions     첫 글 → 요약 · 리액션 · 어휘 · 질문 12~15개
  /api/chat          답변 한 턴 → 리액션 · 교정 · 표현 · 새 질문
  /api/review        대화 전체 → 복습 노트
static/              index.html · app.js · style.css (바닐라 JS, 빌드 도구 없음)
smoke_test.py        모델을 목으로 대체한 엔드투엔드 배선 테스트
```

- 대화 기록은 **브라우저가 들고 있고** 매 요청마다 서버로 보냅니다. 서버는 상태를 갖지 않아서
  그대로 여러 명이 동시에 써도 됩니다. (계정 · 저장 기능은 아직 없습니다.)
- 모든 응답은 **structured outputs**(JSON 스키마)로 받기 때문에 파싱이 깨지지 않습니다.
- 질문 각도 규칙이 들어 있는 시스템 프롬프트는 **프롬프트 캐싱**을 걸어 두어
  두 번째 턴부터 입력 비용이 줄어듭니다.
- 모델은 `claude-opus-5`, adaptive thinking 사용. 대화 턴은 `effort: low`(응답 속도),
  질문 생성과 복습은 `effort: medium` 입니다.
- Opus 5 는 드물게 요청을 거절할 수 있어(`stop_reason: "refusal"`) 서버사이드 폴백을
  기본으로 켜 두었습니다. 계정에서 해당 베타를 쓸 수 없으면 자동으로 끄고 재시도합니다.

## 비용 (대략)

Claude Opus 5 공개 단가($5 / 100만 입력 토큰, $25 / 100만 출력 토큰) 기준 어림값입니다.

- 첫 질문 생성 1회: 약 $0.03~0.05
- 대화 한 턴: 약 $0.02~0.03
- 20턴 한 세션: 대략 $0.5 안팎

비용을 낮추고 싶으면 `ENGLISH_BUDDY_MODEL=claude-sonnet-5`($2/$10) 또는
`claude-haiku-4-5`($1/$5)로 바꿔서 질문 품질을 직접 비교해 보세요.

## 아직 없는 것 (다음 단계 후보)

- 음성: 마이크 입력(STT)과 읽어 주기(TTS) — 브라우저 Web Speech API 로 붙일 수 있습니다.
- 저장/복습: 지금은 새로고침하면 대화가 사라집니다. SQLite 한 파일이면 충분합니다.
- 간격 반복(SRS): 복습 노트의 표현을 다음 세션 질문에 자동으로 섞어 넣기.
- 모바일 앱: 지금 구조(HTTP + JSON)를 그대로 두고 화면만 네이티브로 바꾸면 됩니다.
