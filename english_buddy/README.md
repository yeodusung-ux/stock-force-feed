# English Buddy

일기 · 상황 설명 · 주제를 입력하면, **그 내용에 대해서만** 최대한 다양한 각도로 질문하며
영어 대화를 이어가는 학습 앱입니다. 폰에 설치해서 쓸 수 있고, PC에서 서버로 띄워 쓸 수도 있습니다.

**돈 안 들이고 쓸 수 있습니다.** Google Gemini 무료 티어 키(AIza…)를 넣으면 요금이 청구되지 않고,
품질을 우선하고 싶으면 Anthropic Claude 키(sk-ant-…)를 넣으면 됩니다. 붙여넣은 키 형식을 보고
앱이 알아서 해당 서비스로 붙습니다.

## 무엇을 하는가

1. 한국어든 영어든 원하는 내용을 씁니다. (오늘의 일기 / 상황 설명 / 주제 중 선택)
2. 앱이 그 글을 읽고 **12~15개의 질문을 서로 다른 각도로** 만들어 줍니다.
   사실 · 묘사 · 감정 · 이유 · 의견 · 비교 · 가정 · 과거 경험 · 앞으로 · 상대 입장 ·
   문화 비교 · 표현 확장 · 역할극 · 요약 도전 — 14가지 각도를 돌아가며 사용하고,
   이미 물어본 질문은 다시 묻지 않습니다.
3. 답을 하면 매 턴마다
   - 내용에 대한 자연스러운 영어 리액션 (+ 한국어 번역)
   - 틀린 부분 교정 (진짜 틀린 것만, 없으면 지적하지 않음)
   - 더 자연스러운 표현 1~3개
   - 답변에서 파생된 **새로운 질문 2~4개**
   를 돌려줍니다. 막히면 한국어로 답해도 되고, 그러면 "영어로는 이렇게" 를 알려줍니다.
4. **말하고 듣기**: 마이크 버튼을 누르면 말한 내용이 그대로 답변창에 받아써지고,
   상대의 영어 문장과 질문은 자동으로 읽어 줍니다. 말풍선과 질문 옆 🔊 버튼으로 하나씩 다시 들을 수도 있고,
   말하기 속도(느리게/보통/빠르게)와 받아쓰기 언어(English/한국어)를 바꿀 수 있습니다.
5. **복습 노트** 버튼을 누르면 그날 대화의 실수 · 표현 · 다시 답해 볼 질문을 정리해 줍니다.

레벨(초급/중급/고급)에 따라 질문 길이, 문법 범위, 한국어 병기 비중이 달라집니다.

## 1. 폰에 설치해서 쓰기 (PWA)

앱스토어 · APK 없이, 폰 브라우저에서 **홈 화면에 추가**하면 아이콘이 생기고 전체화면 앱처럼 열립니다.
브라우저(크롬/사파리) 엔진 위에서 돌기 때문에 **음성 기능이 그대로 동작**합니다.

**주소: https://yeodusung-ux.github.io/stock-force-feed/**

1. 폰에서 크롬(안드로이드) 또는 사파리(아이폰)로 위 주소를 엽니다.
2. 처음 한 번 **API 키**를 입력합니다. 둘 중 아무거나 됩니다.
   - 무료: [Google AI Studio](https://aistudio.google.com/apikey) 에서 받은 `AIza…` 키
   - 품질 우선: [Anthropic 콘솔](https://console.anthropic.com/settings/keys) 에서 받은 `sk-ant-…` 키

   키는 **그 폰의 브라우저 저장소에만** 남고, 대화할 때 폰에서 해당 서비스로 바로 전송됩니다. 중간 서버가 없습니다.
3. 메뉴에서 **홈 화면에 추가**(안드로이드: ⋮ → 앱 설치 / 아이폰: 공유 → 홈 화면에 추가)를 누릅니다.
4. 생긴 아이콘으로 열면 주소창 없이 앱처럼 뜹니다.

> **키 관리**: 페이지 주소는 공개지만 키는 각자 폰에만 있습니다. 다만 **폰 잠금이 풀린 상태면
> 누구나 그 키로 대화할 수 있으니**, 폰을 잃어버렸거나 남에게 넘길 때는 콘솔에서 해당 키를 폐기하세요.
> 앱 상단 「설정」에서 저장된 키를 지울 수도 있습니다.

### 배포는 어떻게 되어 있나

`main` 의 `english_buddy/web/**` 이 바뀌면 `.github/workflows/english-buddy-pages.yml` 이
그 폴더를 **`gh-pages` 브랜치로 발행**하고, 깃허브가 그 브랜치를 Pages 로 서빙합니다.
`gh-pages` 는 빌드 결과물 전용 브랜치라 매번 통째로 덮어써집니다 — 직접 커밋하지 마세요.

### APK 를 원했다면

안드로이드 WebView 는 웹 음성인식(SpeechRecognition)을 지원하지 않아서, APK 로 감싸면 음성 부분을
네이티브 플러그인으로 다시 만들어야 합니다. PWA 는 크롬 엔진을 그대로 쓰기 때문에 그럴 필요가 없고,
설치 시 "출처를 알 수 없는 앱" 허용도 필요 없습니다.

## 2. PC에서 쓰기 (로컬 서버)

이 방식에서는 **키가 PC 밖으로 나가지 않습니다.** 브라우저는 로컬 서버에 요청하고, 서버가 키를 붙여 Claude 로 전달합니다.

### 가장 빠른 방법 (스크립트 한 번)

1. **Claude API 키 발급** — https://console.anthropic.com/settings/keys
2. 이 폴더에서 실행합니다.
   - macOS · Linux: 터미널에서 `./start.sh`
   - Windows: 탐색기에서 **start.bat 더블클릭**
3. 처음 한 번만 키를 물어봅니다. 붙여넣고 Enter 하면 `.env` 에 저장되고 다음부터는 묻지 않습니다.
   (`.env` 는 git 에 올라가지 않습니다.)
4. 브라우저가 열리면 http://localhost:8000 에서 바로 사용합니다. 끄려면 실행한 창에서 `Ctrl+C`.

### 직접 실행하고 싶다면

```bash
pip install -r requirements.txt
export ANTHROPIC_API_KEY=sk-ant-...        # Windows: set ANTHROPIC_API_KEY=sk-ant-...
python server.py                            # http://localhost:8000
```

### 환경변수

| 변수 | 기본값 | 설명 |
|---|---|---|
| `ANTHROPIC_API_KEY` | — | Claude API 키(유료). 있으면 이쪽을 먼저 씁니다 |
| `GEMINI_API_KEY` | — | Gemini API 키(무료 티어). Claude 키가 없을 때 사용됩니다 |
| `PORT` | `8000` | 서버 포트 |
| `ENGLISH_BUDDY_FALLBACKS` | `1` | 서버사이드 폴백 비활성화하려면 `0` |

API 키 없이 배선만 확인하려면:

```bash
python smoke_test.py
```

## 음성 지원 범위

음성은 브라우저 내장 Web Speech API 로 처리합니다. 서버를 거치지 않으므로 추가 비용도, 추가 설치도 없습니다.

| 브라우저 | 읽어주기(TTS) | 받아쓰기(STT) |
|---|---|---|
| Chrome · Edge | O | O |
| Safari (macOS · iOS) | O | O |
| Firefox | O | X (마이크 버튼이 자동으로 숨겨집니다) |

- 마이크는 **HTTPS 또는 localhost** 에서만 동작합니다. 깃허브 Pages 는 HTTPS 라 그대로 됩니다.
- 받아쓰기 중에는 읽어주기가 멈춥니다(스피커 소리가 마이크로 다시 들어가지 않도록).
- 받아쓰기 언어를 한국어로 두면 한국어로 말해도 되고, 그러면 "영어로는 이렇게" 를 돌려줍니다.

## 잘 안 될 때

문제가 생기면 먼저 상단 **「설정」 → 「연결 테스트」** 를 눌러 보세요. 키가 통하는지, 어떤 모델을 쓰는지,
실패라면 서비스가 돌려준 원문 메시지가 그대로 나옵니다. 헤더에 보이는 **버전 표시**로 최신 버전인지도 확인할 수 있습니다.

| 증상 | 해결 |
|---|---|
| 키가 틀렸다고 나옴 | `AIza…`(Gemini) 또는 `sk-ant-…`(Claude) 키인지, 폐기하지 않았는지 확인하세요 |
| 「요청이 너무 잦습니다」 | Gemini 무료 티어의 분당 제한입니다. 30초쯤 뒤에 다시 보내면 됩니다 |
| `credit balance is too low` | 콘솔에서 크레딧을 충전해야 합니다 |
| 폰에서 설치 메뉴가 안 보임 | 주소가 `https://` 인지 확인하세요. 아이폰은 사파리에서만 홈 화면 추가가 됩니다 |
| 마이크 버튼이 안 보임 | 파이어폭스에는 받아쓰기 기능이 없습니다. 크롬 · 엣지 · 사파리를 쓰세요 |
| 마이크를 눌러도 반응이 없음 | 브라우저에서 마이크 권한을 허용했는지 확인하세요 |
| 화면이 옛날 버전으로 보임 | 앱을 껐다 켜면 최신으로 바뀝니다(서비스 워커가 네트워크를 먼저 봅니다). 헤더의 버전 표시로 확인하세요 |
| `HTTP 503 · high demand` | 무료 모델이 혼잡한 것입니다. 앱이 다른 Flash 모델로 바꿔 가며 4번까지 다시 시도하고, 성공한 모델을 기억해 다음부터 먼저 씁니다. 그래도 계속 막히면 몇 분 뒤에 하거나 Claude 키로 바꾸세요 |
| Gemini 가 500 을 돌려줌 | 앱이 마지막에 스키마 없이 한 번 더 시도합니다. 그래도 실패하면 오류 문구에 원인이 그대로 나옵니다 |
| `Address already in use` (PC) | 8000 포트가 사용 중입니다. `PORT=8100 ./start.sh` |

## 구조

```
web/                 앱 전체 (바닐라 JS, 빌드 도구 없음). 이 폴더만으로 폰에서 동작한다
  index.html         화면
  ai.js              프롬프트 · 응답 스키마 · 모델 호출 (Claude/Gemini 양쪽, 앱 로직의 단일 출처)
  app.js             화면 동작
  voice.js           Web Speech API 래퍼 (읽어주기 큐 · 마이크 받아쓰기)
  style.css          스타일 (라이트/다크, 모바일 대응)
  manifest.webmanifest · sw.js · icons/   설치형 앱(PWA)으로 만들어 주는 파일들
server.py            PC 모드용 로컬 서버. web/ 을 내려주고 /api/ai 에 키를 붙여 전달한다
start.sh / start.bat 설치 · 키 입력 · 실행을 한 번에 해 주는 스크립트
smoke_test.py        API 키 없이 서버 배선을 확인하는 테스트
```

- 같은 `web/` 폴더가 두 방식 모두에서 그대로 돌아갑니다. 로컬 서버가 `index.html` 에
  `window.ENGLISH_BUDDY_SERVER = "anthropic" | "gemini"` 를 심어 주면 **서버 모드**(키는 PC에),
  없으면 **직접 모드**(키는 이 기기에, 키 형식으로 제공자 판별)로 동작합니다.
- 프롬프트와 스키마는 한 벌이고, 제공자별 요청 형식 변환만 `ai.js` 안에서 따로 처리합니다
  (Gemini 는 스키마에서 `additionalProperties` 를 받지 않고 대화 중간 `system` 역할이 없어,
  그 지시를 마지막 사용자 발화에 붙입니다).
- 대화 기록은 브라우저가 들고 있다가 매 요청에 함께 보냅니다. 서버는 상태를 갖지 않습니다.
- 모든 응답은 **structured outputs**(JSON 스키마)로 받기 때문에 파싱이 깨지지 않습니다.
- 질문 각도 규칙이 든 시스템 프롬프트에는 **프롬프트 캐싱**을 걸어 두 번째 턴부터 입력 비용이 줍니다.
- Claude 를 쓸 때는 `claude-opus-5` + adaptive thinking, 대화 턴은 `effort: low`(응답 속도),
  질문 생성과 복습은 `effort: medium` 입니다. Gemini 를 쓸 때는 계정에서 쓸 수 있는 Flash 모델
  목록을 받아 최신 것을 고르고 기기에 기억해 둡니다.
- Opus 5 는 드물게 요청을 거절할 수 있어(`stop_reason: "refusal"`) 서버사이드 폴백을 기본으로 켜 두었고,
  계정에서 못 쓰면 자동으로 끄고 재시도합니다.

## 무엇이 얼마나 드나

| | Google Gemini (무료 티어) | Anthropic Claude |
|---|---|---|
| 요금 | **0원** | 쓴 만큼 과금 |
| 모델 | Flash 계열 (앱이 계정에서 쓸 수 있는 최신 Flash 를 자동 선택) | `claude-opus-5` |
| 제한 | 분당 요청 수 제한이 있고, 인기 모델은 가끔 혼잡(HTTP 503)합니다. 앱이 다른 Flash 모델로 자동 대체합니다 | 없음 |
| 품질 | 일상 대화 연습에는 충분합니다 | 질문의 다양성과 교정의 정확도가 더 좋습니다 |
| 한 세션(20턴) | 0원 | 대략 $0.5 안팎 |

- Claude 는 신규 계정에 소액(보통 $5) 크레딧이 주어지므로, 먼저 그것으로 품질을 비교해 본 뒤
  무료로 계속 갈지 정하셔도 됩니다.
- 음성(받아쓰기 · 읽어주기)은 어느 쪽을 쓰든 **브라우저 기능이라 항상 무료**입니다.

## 아직 없는 것 (다음 단계 후보)

- 발음 평가: Web Speech API 는 받아쓴 결과만 주고 발음 점수는 주지 않습니다.
  점수가 필요하면 오디오를 서버로 보내는 별도 음성 평가 서비스가 필요합니다.
- 저장/복습: 지금은 새로고침하면 대화가 사라집니다. 기기 안에 저장(IndexedDB)하면 해결됩니다.
- 간격 반복(SRS): 복습 노트의 표현을 다음 세션 질문에 자동으로 섞어 넣기.
