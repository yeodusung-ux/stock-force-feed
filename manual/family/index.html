1. 처음 설치하기

  1. 관리자가 알려 준 Google Drive 폴더에서 주식비서_패밀리_배포용_v…-install.apk 를 폰으로 내려받아 엽니다.
  2. "출처를 알 수 없는 앱" 허용을 물으면 허용합니다(폰 설정 → 앱 → 특별한 접근 → 알 수 없는 앱 설치).
  3. 설치가 끝나면 앱을 엽니다. 앱 이름은 주식비서 입니다.
  4. Android 13 이상이면 알림 허용 팝업이 먼저 뜹니다. 목표가·시황 알림을 받으려면 허용하세요.

Drive 의 파일은 처음 설치용 입니다. 그 뒤로는 앱 안에서 새 버전을 받습니다(5절). 설치 직후에도 "새 버전" 팝업이 뜨는데, 그때 [지금 업데이트] 를 누르면 정식판(체결알림 자동 입력이 들어 있는 판)이 설치됩니다.

"기기 보호를 위해 앱 차단됨"이 뜨면 관리자에게 알려 주세요. 배포용 APK 는 그 차단을 피하도록 만들었지만 폰 설정에 따라 다를 수 있습니다.

2. 처음 실행 — 초대 코드, 이름·전화번호

2-1. 투자 책임 고지

첫 화면에 "투자 책임 고지"가 한 번 뜹니다. 읽고 [확인] 을 누르세요. 다시 뜨지 않습니다.

2-2. 가족 초대 코드

  • "관리자에게 받은 가족 초대 코드를 넣으세요." 라는 창이 뜹니다. 관리자가 알려 준 초대 코드를 넣고 [연결] 을 누릅니다.
  • 잠시 "확인 중…" 이 지나면 구성원 번호(m01, m02 …)가 자동으로 배정됩니다. 번호는 이 창에 보이지 않고 설정 탭에서 확인합니다(4절).
  • 폰을 바꿔 다시 설치하는 경우에는 초대 코드 대신 예전 구성원 코드를 넣으면 쓰던 자리로 돌아옵니다(2-4).
이런 문구가 뜨면 뜻
초대 코드가 맞지 않습니다 코드를 다시 확인하세요(앞뒤 공백은 자동으로 지워집니다).
가족 정원이 찼습니다 — 관리자에게 알리세요 관리자가 자리를 늘려야 합니다.
초대 코드 가입이 꺼져 있습니다 — 관리자에게 알리세요 관리자가 초대 코드를 다시 켜야 합니다.

2-3. 내 이름·전화번호

  • 다음 창 "내 이름·전화번호"에 실명과 전화번호를 넣고 [저장] 합니다. 별명은 쓰지 마세요.
  • 이 정보는 관리자가 계좌 주인을 확인하고 연락하는 데만 쓰이며 가족 밖으로 나가지 않습니다.
  • 이름은 20자까지, 전화번호는 숫자 9~15자리(010-1234-5678 꼴로 자동 정리)입니다. 둘 다 채워야 [저장] 이 켜집니다.
  • 나중에 설정 탭의 [이름·전화번호 수정] 으로 바꿀 수 있습니다.

2-4. 폰을 바꾸거나 앱을 지웠다면

  1. 관리자에게 내 구성원 번호(m01 …)로 코드 재발급을 요청하세요. 번호는 설정 탭 맨 위 "구성원 m01: 이름" 줄에 있습니다.
  2. 새 폰에서 앱을 설치하고 첫 화면(2-2)에 받은 코드를 넣으면 같은 번호로 돌아오고, 이름·전화번호도 자동으로 채워집니다.
  3. 앱 안에는 연결을 끊거나 코드를 꺼내는 메뉴가 없습니다.

3. 화면 구성

아래 5개 탭이 있습니다. 탭 이름을 누르거나, 탭 줄 위에서 좌우로 밀어 옆 탭으로 갈 수 있습니다.

탭 하는 일
동향 환율·지수 미니차트, 오늘의 시황, 뉴스·리포트·공시·공모주
검색 종목·업종·테마·리포트 탐색, 조건 검색(퀀트검색), 관리자가 만든 저장 검색
관심 관심 종목을 그룹으로 관리, 그룹별 자동매매 스위치
보유 보유 종목과 손익, 매매기록, 종료거래, 매매리포트
설정 앱 업데이트, 알림, 내 구성원 정보, 자동매매 설정, 체결알림 자동 입력

공통 동작: - 목록 화면은 아래로 당겨서 새로고침합니다. - 종목을 누르면 종목 상세(10절)로 갑니다. 상세에서 좌우로 밀면 방금 보던 목록의 옆 종목으로 넘어갑니다(상단에 "3 / 20" 처럼 위치가 보입니다). - 화면 위 돋보기는 종목 검색입니다. "삼성전자", "005930" 처럼 이름이나 코드를 넣으세요.

4. 설정 탭

위에서부터 순서대로입니다.

  1. 앱 업데이트 줄 — v0.9.275 · 최신 처럼 현재 버전과 상태가 보입니다. 줄을 누르면 다시 확인하고, 새 버전이면 [업데이트] 버튼이 나타납니다(5절).
  2. 구성원 m01: 이름 · 전화번호 — 바로 아래 줄. 내 번호와 정보이며 [이름·전화번호 수정] 으로 바꿉니다.
  3. 알림설정 — 시황·목표가·공시·급등락·배당·공모주 알림을 항목별로 켜고 끕니다(6절).
  4. X(트위터) 채널 — 관리자가 시황·분석 글을 올리는 계정으로 이동합니다.
  5. 사용 설명서 — 이 문서를 엽니다.
  6. 관리자 › 키움 자동매매 설정 — 가족 PC 에 설치된 자동매매 엔진의 설정을 원격으로 바꿉니다(12절). 화면 문구에 "집 PC" 라고 되어 있지만 내 가족 PC 엔진이 대상입니다. 엔진이 없으면 같은 화면이 폰에만 저장되는 설정으로 바뀌고, 그 값으로 차트의 예상 매매선이 계산됩니다(12-2).
  7. 체결알림으로 보유 자동 입력 — 증권사 체결알림(카카오톡·문자)을 읽어 보유와 매매기록을 자동으로 채웁니다(11-4절). 처음 설치용 APK 에서는 이 카드가 "과거 체결 가져오기" 로만 보이며, 앱 내 업데이트로 정식판을 받으면 스위치가 나타납니다.

5. 앱 업데이트

  • 앱을 열 때와 앱으로 돌아올 때(10분마다) 새 버전을 자동으로 확인합니다.
  • 새 버전이 있으면 "새 버전 v…" 팝업이 뜹니다. [지금 업데이트] 를 누르면 내려받기 → 설치 화면 순서로 진행되고, 설치 화면에서 [설치] 만 누르면 됩니다. [나중에] 를 누르면 이번 실행 동안만 닫히고, 화면 위에 "새 버전 v… 준비됨 — 눌러서 내려받아 설치" 띠가 남습니다.
  • 처음 한 번은 "알 수 없는 앱 설치" 허용을 묻는 설정 화면이 열릴 수 있습니다. 주식비서를 허용하고 돌아와서 띠를 다시 누르세요.
  • 설정 탭 첫 줄에서 [최신 받기] 로 수동 확인도 됩니다.
  • "내려받기 실패" 가 뜨면 네트워크를 확인하고 다시 누르세요. 계속 실패하면 관리자에게 알려 주세요.

6. 알림

설정 탭 → 알림설정. 모든 알림은 기본 꺼짐이고 원하는 것만 켭니다. 알림은 약 30분 주기로 확인하므로 정확한 시각 알림이 아닙니다.

7. 동향 탭

7-1. 환율·지수 타일

  • 맨 위 줄: 달러 · 유로 · 엔(100) · 위안 환율. 엔은 100엔 기준입니다.
  • 둘째 줄: 코스피 · 코스닥 · 업비트 종합. 업비트 종합은 업비트에 상장된 코인 중 시가총액 상위 10개를 시총가중으로 묶어 앱이 직접 계산한 지수(기준 1,000)입니다. 방향과 등락률 참고용이며 업비트 공식 지수와 값이 다릅니다.
  • 셋째 줄: 다우 · 나스닥 · S&P 500. 넷째 줄: 상해 · 항셍 · 니케이.
  • 각 타일은 값·등락률·당일 흐름 선차트를 보여 주고, 화면이 보이는 동안 1분마다 조용히 갱신됩니다. 타일을 누르면 상세 차트로 가고, 코스피·코스닥·업비트 종합 상세에는 구성종목(시가총액 순) 카드가 있습니다.

7-2. 오늘의 시황

  • 관리자 PC 가 발행한 AI 작성 시황입니다. 본문은 200자 요약이고, 누르거나 "▾ 전체 시황 보기" 를 누르면 전문이 펼쳐집니다.
  • 오른쪽 스피커 아이콘은 읽어주기입니다. 다시 누르면 멈추고, 화면을 벗어나면 자동으로 멈춥니다.
  • "아직 발행된 시황이 없습니다" 는 장전·마감 후 발행 전이라는 뜻입니다.

7-3. 뉴스·리포트·공시·공모주

  • 이슈 뉴스(최근 12시간 헤드라인), 최신 뉴스, 최신 리포트(증권사 리서치), 최신 공시(48시간), IPO 일정 카드가 이어집니다.
  • 각 카드는 3건만 보이고 "+ N개 더보기" 로 펼칩니다. 행을 누르면 원문이 브라우저로 열립니다(IPO 일정은 열리지 않습니다).

8. 검색 탭

위쪽 칩 줄: 탐색 → 퀀트검색 → 저장 검색들. 칩을 누르거나 화면을 좌우로 밀어 옮깁니다. 처음 열면 퀀트검색입니다.

8-1. 탐색

  • 종목: "삼전", "ㅅㅅㅈㅈ", "0059" 처럼 대충 쳐도 찾습니다. 아무것도 안 치면 최근 본 종목과 지금 오른 종목(장중 1분 갱신)이 보입니다.
  • 업종 / 테마: 관리자 PC 가 저녁에 발행한 자료로, 등락률 순 카드입니다. 카드를 누르면 그 업종의 수급 상위 종목 표가 펼쳐집니다. "아직 발행 전입니다" 는 저녁 수집 전이라는 뜻입니다.
  • 리포트: 최근 3·7·14·30일(또는 기간 지정) 동안 리포트가 많이 나온 종목 순위. 행을 누르면 상세, ▾ 를 누르면 그 기간의 리포트 목록.

8-2. 퀀트검색(조건 검색)

  • 시총·가격·거래대금·PER·PBR·ROE·EPS·BPS·PSR·영업이익·고점대비하락·상승률·이격도 조건을 넣고 [검색] 을 누릅니다. 빈칸은 적용하지 않습니다. ≤ 는 입력값 이하(PER·PBR·PSR 은 낮을수록 저평가), ≥ 는 이상입니다.
  • "기간 조건" 묶음은 최근 N개 사업연도의 평균·최소 영업이익률과 배당수익률로 거릅니다. 기간(년)을 비우면 지금 값으로 판정합니다.
  • [↺ 리셋] 은 관리자가 발행한 기본 조건으로 되돌립니다. 관리자가 기본 조건을 새로 발행하면 내 조건도 그 값으로 바뀝니다.
  • 결과 표는 헤더(종목명·현재가·등락·등락률)를 눌러 정렬합니다. 종목 이름 앞의 🟢 는 가족 PC 엔진이 보유 중, 🔴 는 정리 중이라는 표시입니다.
  • 행 오른쪽 ⋮ 에서 관심종목에 추가(그룹 선택 또는 새 그룹), 관심종목에서 제거, 보유종목에 추가(수량·평단 입력, 설정 탭의 체결알림 스위치가 켜져 있을 때 의미 있음)를 할 수 있습니다. "전체 관심추가 (N)" 는 결과 전체를 한 그룹에 넣습니다.
  • 결과가 0건이면 어느 조건에서 다 걸러졌는지 안내가 나옵니다. 그 값을 낮추거나 비우세요.

8-3. 저장 검색(관리자가 만든 검색)

  • 관리자가 조건을 만들어 발행한 검색입니다. 조건을 바꾸거나 저장·삭제할 수는 없고, 결과 보기·정렬·[↻ 새로고침] 만 됩니다.
  • 자동 ON/OFF 스위치: 켜면 지금 검색 결과가 내 가족 PC 엔진의 매매 대상 목록으로 전송됩니다("자동매매 ON — 조건에서 빠지면 청산됩니다"). ON 일 때 ⚡빠른청산 도 켤 수 있습니다. 앱을 열어 조회할 때마다 목록이 갱신되고, 앱을 열지 않으면 마지막 목록으로 계속 매매합니다. 가족 PC 엔진이 없으면 아무 일도 일어나지 않습니다.

9. 관심 탭

9-1. 그룹과 종목

  • 화면 위 그룹 칩을 눌러 그룹을 고릅니다(둘 이상이면 좌우로 밀어도 됩니다). 기본 그룹 이름은 "기본" 입니다.
  • 📁(관심그룹 관리): "새 그룹 추가", ✎ 이름 바꾸기, 🗑 삭제(그 그룹에만 있던 종목은 관심에서 함께 빠집니다), ≡ 를 잡고 끌어 순서 변경.
  • ＋(종목 추가): 이름·초성·코드를 치고 후보의 "+ 추가" 를 누릅니다. 연속으로 여러 종목을 넣을 수 있습니다. 종목 상세의 ★, 검색 탭의 ⋮ 로도 추가됩니다.
  • 목록은 헤더를 눌러 정렬하고, 정렬을 풀면 행을 길게 눌러 끌어 순서를 바꿀 수 있습니다.
  • 행 오른쪽 ⋮: "그룹 편집"(여러 그룹에 동시에 넣기), "관심 삭제 (모든 그룹)".
  • 시세는 화면이 보이는 동안 15초마다 갱신됩니다. 미니차트 위 "자동"/"정리" 배지는 가족 PC 엔진이 그 종목을 관리 중이라는 뜻입니다.

9-2. ⚡ 그룹별 자동매매

  • 헤더의 ⚡ 를 누르면 "키움 자동매매 (관심그룹별)" 창이 열립니다. 켜진 그룹의 국내 종목을 가족 PC 엔진이 1차 매수하고 물타기·트레일링으로 관리합니다. 코인·해외는 자동 제외됩니다.
  • 드라이런(모의) 스위치가 기본 ON 이며, 이때는 실주문을 내지 않습니다. 실주문은 관리자와 상의한 뒤 끄세요.
  • "대상 상한" 은 켜진 그룹 전체에서 매매할 최대 종목 수입니다(기본 20).
  • "⚠️ 엔진 전송 실패" 띠가 보이면 아무 스위치나 다시 켰다 꺼서 재전송하세요.

10. 종목 상세

10-1. 상단

  • 종목명 오른쪽에 "i / N"(옆으로 넘길 수 있는 위치). 아이콘: 🛒 주문(국내 종목), 📋 매매리포트(보유 중이거나 끝난 매매가 있을 때), ⚙ 평단·목표가 설정, ★ 관심.
  • 현재가와 등락은 국내 종목은 장중 2초마다, 코인·해외는 15초마다 갱신됩니다.

10-2. 차트

  • 봉 칩: N분봉 · 일봉 · 주봉 · 월봉. 분봉을 고르면 아래에 1·3·5·10·15·30·60분 칩이 나옵니다. 고른 간격은 다른 종목에도 유지됩니다.
  • 5·15·30분봉은 최근 60일, 60분봉은 최근 1년, 1·3·10분봉은 최근 7거래일까지 나옵니다.
  • 보조지표 칩(봉 칩 아래 줄): 볼린저 · 일목 · RSI · MACD · 스토캐스틱 · OBV. 고른 지표는 다른 종목에도 유지됩니다.
  • 볼린저(20일, 2σ)는 캔들 위에 겹쳐 그립니다. 상·하단선과 옅은 밴드가 나오고, 중심선은 MA20 과 같습니다. 왼쪽 위에 "BB(20,2) 상 … · 하 …" 값이 보입니다.
  • 일목(일목균형표 9, 26, 52)도 캔들 위에 겹칩니다. 전환선(빨강)·기준선(파랑)·후행스팬(초록)과 구름대가 나오고, 선행스팬1이 위면 붉은 구름, 선행스팬2가 위면 푸른 구름입니다. 선행스팬은 25봉 앞에 그려지므로 일목을 켜면 최신 봉 오른쪽에 그만큼 빈 공간이 생깁니다(과거로 넘기면 사라집니다). 후행스팬은 종가를 25봉 뒤로 옮긴 선입니다.
  • RSI(14) · MACD(12, 26, 9) · 스토캐스틱(14, 3, 3) · OBV 는 거래량 아래 패널에 하나만 나옵니다. 같은 칩을 다시 누르면 꺼집니다.
  • OBV 는 종가가 오른 봉의 거래량을 더하고 내린 봉의 거래량을 빼서 쌓은 선이며, 9봉 평균 시그널선이 함께 나옵니다. 숫자의 크기는 받은 봉의 시작점에 따라 달라지므로 HTS 와 값이 달라도 정상이고, 선의 방향과 기울기를 봅니다. RSI 는 70·30, 스토캐스틱은 80·20 기준선이 점선으로 그려지고, MACD 는 MACD 선(빨강)·시그널(파랑)·막대(히스토그램)입니다.
  • 차트를 한 번 눌러 십자선을 세우면 그 봉의 지표값이 패널 왼쪽 위에 나옵니다. 십자선이 없으면 화면의 마지막 봉 값입니다.
  • 계산식은 HTS·네이버 차트와 같은 표준식(RSI 와일더 평활, MACD 지수이동평균)입니다. 다만 RSI·MACD 는 앞쪽 봉이 많을수록 정확해서, 막 상장한 종목이나 봉이 적은 차트의 왼쪽 끝은 HTS 와 조금 다를 수 있습니다.
  • 두 손가락으로 확대·이동합니다(한 손가락은 화면 스크롤과 옆 종목 넘기기용). 한 번 누르면 십자선과 시·고·저·종·거래량이, 두 번 누르면 세력차트(자료가 있을 때)로 바뀝니다.
  • 선: "현재가" 점선, "평단"(내가 저장한 평단), "목표"(저장한 목표가), 매매 계획선(추가매수·분할매도·손절·⚡빠른 트레일링). 차트 범위 밖에 있는 선은 위·아래 가장자리에 "▲평단 27,640" 처럼 라벨만 붙습니다.
  • 가족 PC 엔진이 들고 있는 종목은 엔진이 계산한 계획선이 그대로 나옵니다.
  • 엔진이 없거나 엔진이 들고 있지 않은 보유 종목은 앱이 같은 규칙으로 직접 계산해 "예상 추가매수 23,450원 11주" 처럼 라벨 앞에 "예상" 을 붙여 그립니다. 자동매매를 켜지 않아도 나옵니다(12-2).
  • 마커: ●빨강 매수 / ●파랑 매도(내 체결, "1차매수 3주"·"매도 5주"), ▲▼ 엔진 전략의 진입·이탈, ◆ 내부자 취득·처분, 🚩 공시(유상증자·자사주·감자 등). 분봉에서는 전략·공시 마커를 그리지 않습니다.

10-3. 호가 · 재무정보 · 배당 이력 · 기업정보 (국내 종목)

  • 호가 카드는 접혀 있고 "매수 N · 매도 N"(총잔량)을 보여 줍니다. 누르면 매도 5단·매수 5단.

10-4. 평단·목표가 설정(⚙)

  • "평단가 (비우면 삭제)": 보유 종목이면 보유 평단이 자동으로 채워집니다. [저장] 을 눌러야 차트의 평단선과 평단 알림에 반영됩니다.
  • 매매기록 표(11-3 과 같은 표)에서 매수·매도 줄을 직접 넣을 수 있습니다.
  • "목표가 (비우면 삭제)": 저장하면 차트에 목표선이 그려지고 목표가 알림의 기준이 됩니다.

10-5. 주문(🛒, 국내 종목)

  • 가족 PC 에 자동매매 엔진이 설치된 경우에만 의미가 있습니다. 매수/매도, 시장가 또는 지정가, 수량을 넣고 [매수 주문]/[매도 주문] 을 누르면 "PC가 곧(최대 30초) 발주합니다" 안내가 뜹니다. 실제 발주는 가족 PC 엔진이 장중 여부와 보유 수량을 다시 확인한 뒤 합니다.

10-6. 코인·지수 상세

  • 코인 상세에는 호가·재무·배당·기업정보 카드가 없고 24시간 15초 갱신입니다.

  • 설정 탭 스위치가 꺼져 있으면 "보유 수량·평단은 동기화분이라 여기서 바꾸지 않습니다 — 매매기록과 목표가만 저장됩니다." 가 안내되고, 켜져 있으면 [이 종목 삭제] 와 [저장(전량매도)] 도 쓸 수 있습니다.

11-4. 과거 체결내역 가져오기

카카오톡 대화 내보내기 1. 카카오톡에서 '키움증권 체결알림' 채팅방을 엽니다 → 오른쪽 위 메뉴 → 대화 내보내기. 2. 공유 대상에서 [주식비서] 를 고릅니다(앱 안 설정 탭의 [파일 가져오기] 로 저장해 둔 파일을 골라도 됩니다). 3. "과거 체결 가져오기" 창에 "발견 N건(기간) · 반영 x · 코드 못 찾음 y · 이미 있음 z" 가 나오면 끝입니다. - "코드 못 찾음" 은 종목명이 전종목 명부와 정확히 맞지 않은 경우입니다. 그 줄은 11-3 표에서 직접 넣어 주세요. - "체결통보를 찾지 못했습니다" 가 나오면 체결알림 채팅방을 내보낸 파일이 맞는지 확인하세요. 4. 같은 날·같은 구분·같은 수량·같은 단가의 체결은 한 번만 들어갑니다(중복 안심).

문자함 가져오기(정식판, 설정 탭 [문자 가져오기]): 받은 문자함에서 체결통보 문자만 읽어 넣습니다. 처음 누를 때 문자 읽기 권한을 묻습니다.

체결알림 자동 입력(정식판, 설정 탭 스위치): 켜면 "알림 접근" 설정이 열립니다. 주식비서를 허용하고, 카카오톡 알림 미리보기가 켜져 있는지 확인하세요. 이미 갖고 있던 종목은 한 번 직접 넣어 주고, 그 뒤 체결부터 자동으로 들어갑니다. "최근 잡힌 체결" 5건과 [자체 점검] 으로 동작을 확인할 수 있습니다.

지원하는 알림 문구: "[키움]체결통보 / 종목 / 매수1주 / 평균단가215,000원", "[키움]일부체결통보 …" 등 키움 체결통보 형식입니다. 취소·거부·주문접수 안내는 무시합니다.

11-5. 종료거래

  • 보유 탭 헤더의 📦 를 누릅니다. 전량 매도로 끝난 매매가 모입니다(매수·매도가 모두 기록에 있어야 집계).
  • 위 카드: 종료거래 합계(건수·종목수), 실현손익, 수익률(실현 ÷ 매수대금), 승률, 이익/손실 건수.
  • 표: 종목 · 실현손익 · 수익률, 아래 줄에 "N회차 · 기간 · 보유일 · 주수 · 체결 건수". 행을 누르면 종목 상세, 줄 끝 아이콘을 누르면 그 매매의 리포트.

11-6. 매매리포트

  • 보유 탭 수익률 셀, 종료거래 줄 끝 아이콘, 종목 상세 📋 에서 엽니다.
  • 카드에는 종목·합계손익·수익률, 보유/평단/보유기간/연환산, 차트(평단선·매수▲·매도▼ 마커), 매매내역 표, 실현·평가·합계손익이 담깁니다.
  • 카드 아래 조작(캡처엔 안 들어감): 봉 칩(분봉이면 1~60분 간격 칩), [−][+][전체] 와 두 손가락 확대·드래그, "금액 가리기"(손익·수량을 ••• 로), "세력평단"(자료가 있을 때).
  • [이미지 복사] 는 카드 이미지를 클립보드에 넣고, [공유] 는 다른 앱으로 보냅니다.

12. 키움 자동매매 설정(가족 PC 에 엔진을 설치한 경우)

설정 탭 → 관리자 › 키움 자동매매 설정. 가족 PC 엔진이 발행한 현재 설정을 읽어 온 뒤, 바꾼 항목만 전송합니다. 엔진이 없거나 아직 설정을 발행하지 않았으면 "현재 설정 못 불러옴 → 아래는 기본값, 토글 잠김" 상태입니다.

묶음 항목
자동매매 상태 자동매매 ON/OFF, 긴급정지(ON=전면중단), 편집 대상 계좌, 최대 보유종목수
① 최초진입 종목당 매수금액, 신규진입 계좌수익률 기준
② 분할매수(물타기) 사용 여부, 트리거 수익률, 추가진입 비율, 종목당 최대 보유금액(0 불가), 시총 티어별 최대 차수
③ 분할매도(트레일링 사다리) 기본 목표, 차수당 목표 추가, 수익반납률
④ 최종청산 정리 대상 손절, 빠른 트레일링(발동 고점수익률·청산 반납률·적용 대상)

[변경분 전송] 을 누르면 "실거래 설정 변경" 확인 창에 바뀐 항목이 나열됩니다. 실제 매매에 즉시 영향을 주므로 관리자와 상의한 값만 보내세요.

12-2. 엔진이 없을 때 — 예상 매매선용 설정

  • 가족 PC 에 엔진이 없으면 이 화면 위에 "PC 자동매매 엔진 없음 — 아래 값은 이 폰에만 저장되며 …" 안내가 나오고, 버튼이 [이 폰에 저장] 으로 바뀝니다. 실제 주문은 나가지 않습니다.
  • 기본값은 관리자 설정과 같습니다(추가매수 -15%, 분할매도 목표 +20%·차수당 +10%, 수익반납률 20%, 종목당 1차 25만원·최대 1,500만원 등). 원하는 값으로 바꿔 저장하면 종목 상세 차트의 예상선이 그 값으로 다시 계산됩니다.
  • 예상선이 그려지는 조건
선 언제 그려지나
예상 추가매수(가격·수량) 물타기 사용 ON 이고 차수 여력이 있을 때. 평단 × (1 + 트리거 수익률) 을 주문 가능한 호가로 내림
예상 분할매도(가격·수량) 2차 이상 매수했을 때. 발동 전에는 발동 목표가, 매수 후 고점이 목표를 넘으면 스탑가(고점 수익의 반납률만큼 내려온 가격)로 바뀜
예상 최대차수손절 손절률을 0 보다 크게 넣었고, 더 추가매수할 수 없는 상태(최대 차수 도달·물타기 OFF)일 때
예상 ⚡발동 / ⚡청산 빠른 트레일링 사용 ON + "수동 보유분에 적용" ON 일 때
  • 차수와 매수 후 고점은 매매기록(11-3)에서 읽습니다. 매수 줄이 2건이면 2차, 부분 매도하면 한 차수 내려갑니다. 매매기록이 비어 있으면 1차로 보고 추가매수 예상선만 나옵니다.
  • 예수금 부족 같은 계좌 사정은 앱이 알 수 없어 반영되지 않습니다. 참고용 가격입니다.

13. 자주 묻는 문제

증상 확인할 것
시세가 "—" 로 나오거나 안 움직인다 네트워크 확인. 국내 종목 실시간은 평일 09:00~15:30 에만 돌고 그 밖에는 마지막 값이 보입니다.
새 버전 팝업이 안 뜬다 설정 탭 첫 줄을 눌러 수동 확인. "확인 실패" 면 잠시 뒤 다시.
업데이트 설치가 막힌다 폰 설정 → 알 수 없는 앱 설치 → 주식비서 허용 후 화면 위 띠를 다시 누르세요.
카톡 체결이 자동으로 안 들어온다 정식판인지(설정 탭 카드에 스위치가 있는지), 알림 접근 허용, 카카오톡 알림 미리보기 켜짐, 알림 문구에 "체결통보" 가 있는지. [자체 점검] 결과를 관리자에게 보내 주세요.
종목이 "코드 못 찾음" 으로 빠진다 알림의 종목명이 정식 명칭과 다른 경우입니다. 매매기록 편집에서 직접 넣어 주세요.
보유 탭이 비어 있다 가족 PC 엔진이 없으면 설정 탭 스위치를 켜고 ＋ 로 넣거나 카카오톡 내보내기로 채우세요.
앱을 지우고 다시 깔았다 2-4 대로 관리자에게 코드를 재발급받아 복귀. 관심·목표가·매매기록은 폰 안에 있던 것이라 지워지면 되살릴 수 없습니다.
앱 오류 화면이 떴다 화면을 캡처해 관리자에게 보내 주세요.
