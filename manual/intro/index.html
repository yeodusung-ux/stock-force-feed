왜 만들었나

증권사 앱은 계좌마다 따로 열어야 하고, 시황은 뉴스 앱에서, 조건 검색은 HTS 에서, 목표가 알림은 또 다른 앱에서 봐야 합니다. 주식비서는 이걸 한 화면 흐름으로 묶었습니다.

  • 아침에 동향 탭을 열면 환율·지수·시황·뉴스가 한 번에 보입니다.
  • 검색 탭에서 조건으로 종목을 거르고, 마음에 들면 바로 관심 그룹에 넣습니다.
  • 종목 상세에서 분봉부터 월봉까지 차트를 보고, 평단·목표가를 저장하면 알림이 옵니다.
  • 보유 탭은 증권사 체결알림(카카오톡·문자)을 읽어 스스로 채워집니다. 손익과 수익률은 장중에 2초마다 움직입니다.
  • 가족 PC 에 자동매매 엔진을 두었다면, 앱에서 엔진 설정을 바꾸고 주문도 보낼 수 있습니다.

가족 버전은 관리자(가족 중 한 사람)가 초대 코드를 나눠 주고, 각자 폰에 설치해 씁니다. 관리자 PC 가 저녁마다 발행하는 업종·테마·시황 자료를 온 가족이 같이 봅니다.

1. 설치와 첫 실행 — 3분이면 끝

  1. 관리자가 알려 준 Drive 폴더에서 주식비서_패밀리_배포용_v…-install.apk 를 받아 엽니다. "출처를 알 수 없는 앱" 허용을 물으면 허용합니다.
  2. 앱을 열면 투자 책임 고지가 한 번 뜹니다.
  3. 가족 초대 코드를 넣고 [연결] 하면 구성원 번호(m01, m02 …)가 자동으로 배정됩니다.
  4. 이름과 전화번호를 넣습니다. 관리자가 계좌 주인을 확인하고 연락하는 데만 쓰이고 가족 밖으로 나가지 않습니다.

이게 전부입니다. 계정 만들기도, 이메일 인증도 없습니다. 설치 직후 "새 버전" 팝업이 뜨면 [지금 업데이트] 를 눌러 정식판을 받으세요. 처음 설치용 파일은 폰 보안 검사를 피하려고 일부 기능(체결알림 자동 입력)을 뺀 판이라, 앱 안에서 한 번 업데이트하면 전체 기능이 켜집니다.

폰을 바꾸면 관리자에게 코드를 재발급받아 같은 번호로 돌아옵니다. 이름·전화번호도 자동으로 채워집니다.

3. 검색 탭 — 종목을 찾는 네 가지 길

위쪽 칩 줄이 탐색 → 퀀트검색 → 저장 검색들 순서입니다.

탐색

  • 종목: "삼전", "ㅅㅅㅈㅈ", "0059" 처럼 대충 쳐도 찾습니다. 초성 검색이 되니 이름이 긴 종목도 금방입니다. 아무것도 안 치면 최근 본 종목과 지금 오른 종목(장중 1분 갱신)이 보입니다.
  • 업종 / 테마: 관리자 PC 가 저녁에 발행한 자료로, 등락률 순 카드입니다. 카드를 누르면 그 업종의 수급 상위 종목 표가 펼쳐집니다.
  • 리포트: 최근 3·7·14·30일(또는 직접 지정) 동안 증권사 리포트가 많이 나온 종목 순위입니다. 애널리스트 관심이 몰리는 종목을 거꾸로 찾는 방법입니다.

퀀트검색 — 13개 조건으로 거르기

시총 · 가격 · 거래대금 · PER · PBR · ROE · EPS · BPS · PSR · 영업이익 · 고점대비하락 · 상승률 · 이격도 조건을 넣고 [검색] 합니다. 빈칸은 적용하지 않으니 두세 개만 넣어도 됩니다. ≤ 는 입력값 이하, ≥ 는 이상입니다.

여기에 기간 조건 묶음이 있습니다. 최근 N개 사업연도의 평균·최소 영업이익률과 배당수익률로 거릅니다. "최근 5년 동안 한 해도 영업이익률 10% 아래로 안 떨어진 종목" 같은 조건이 됩니다.

  • [↺ 리셋] 은 관리자가 발행한 기본 조건으로 돌아갑니다.
  • 결과 표는 헤더를 눌러 정렬합니다. 종목 이름 앞의 🟢 는 가족 PC 엔진이 보유 중, 🔴 는 정리 중이라는 표시입니다.
  • 행 오른쪽 ⋮ 에서 관심종목에 추가(그룹 선택), 보유종목에 추가(수량·평단)를 바로 합니다. "전체 관심추가 (N)" 로 결과 전체를 한 그룹에 넣을 수도 있습니다.
  • 결과가 0건이면 어느 조건에서 다 걸러졌는지 안내가 나옵니다. 그 값만 풀면 됩니다.

저장 검색 — 관리자가 만든 검색, 자동매매로 연결

관리자가 조건을 만들어 발행한 검색입니다. 결과 보기·정렬·새로고침만 되고 조건은 못 바꿉니다. 대신 자동 ON/OFF 스위치가 있어, 켜면 지금 검색 결과가 내 가족 PC 엔진의 매매 대상 목록으로 전송됩니다. 조건에서 빠지면 청산되고, ⚡빠른청산도 켤 수 있습니다. 엔진이 없으면 아무 일도 일어나지 않습니다.

4. 관심 탭 — 그룹으로 나눠 보기

  • 그룹 칩으로 "배당주", "관찰중" 처럼 나눠 관리합니다. 📁 에서 그룹 추가·이름 변경·삭제·순서 변경(≡ 끌기)을 합니다.
  • ＋ 로 이름·초성·코드를 쳐서 연속으로 여러 종목을 넣습니다. 종목 상세의 ★, 검색 탭의 ⋮ 로도 들어옵니다. 한 종목을 여러 그룹에 동시에 넣을 수도 있습니다("그룹 편집").
  • 목록은 헤더로 정렬하고, 정렬을 풀면 행을 길게 눌러 끌어 순서를 바꿉니다.
  • 시세는 화면이 보이는 동안 15초마다 갱신되고, 미니차트 위 "자동"/"정리" 배지는 가족 PC 엔진이 그 종목을 관리 중이라는 뜻입니다.

⚡ 그룹별 자동매매

헤더의 ⚡ 를 누르면 "키움 자동매매 (관심그룹별)" 창이 열립니다. 켜진 그룹의 국내 종목을 가족 PC 엔진이 1차 매수하고 물타기·트레일링으로 관리합니다. 드라이런(모의) 이 기본 ON 이라 실주문은 나가지 않으며, 실주문은 관리자와 상의한 뒤 끕니다. "대상 상한"(기본 20)으로 매매 종목 수를 제한합니다.

5. 종목 상세 — 차트 하나에 다 그린다

차트

  • 봉 칩: N분봉 · 일봉 · 주봉 · 월봉. 분봉을 고르면 1·3·5·10·15·30·60분 칩이 나오고, 고른 간격은 다른 종목에도 유지됩니다.
  • 볼 수 있는 기간: 5·15·30분봉은 최근 60일, 60분봉은 최근 1년, 1·3·10분봉은 최근 7거래일. 지난주 매매를 15분봉으로 복기하는 일이 됩니다.
  • 조작: 두 손가락으로 확대·이동(한 손가락은 스크롤과 옆 종목 넘기기), 한 번 누르면 십자선과 시·고·저·종·거래량, 두 번 누르면 세력차트(자료가 있을 때).
  • 차트는 봉 범위에 맞춰 세로축을 꽉 채웁니다. 범위 밖의 평단·목표선은 위·아래 가장자리에 "▲평단 27,640" 처럼 라벨만 붙어 화면을 낭비하지 않습니다.

평단·목표가(⚙)와 주문(🛒)

  • ⚙ 에서 평단가와 목표가를 저장하면 차트에 선이 그려지고 평단 돌파·목표가 돌파 알림의 기준이 됩니다. 같은 창에서 매매기록 줄도 직접 넣을 수 있습니다.
  • 🛒 는 가족 PC 엔진이 있을 때 쓰는 주문입니다. 매수/매도, 시장가/지정가, 수량을 넣으면 엔진이 최대 30초 안에 장중 여부와 보유 수량을 다시 확인한 뒤 발주합니다.

현재가는 국내 종목이 장중 2초, 코인·해외가 15초마다 갱신됩니다. 코인 상세는 24시간 돌고, 지수 상세에는 구성종목 카드가 있습니다.

6. 보유 탭 — 손으로 안 넣어도 채워진다

채우는 네 가지 방법

가족 PC 엔진 동기화 엔진이 있으면 5분마다 자동
체결알림 자동 입력 설정 탭 스위치를 켜면 카카오톡·문자 체결알림이 올 때마다 자동
카카오톡 대화 내보내기 / 문자함 가져오기 과거 체결을 한꺼번에 넣을 때
직접 입력 ＋ 버튼으로 수량·평단

체결알림 자동 입력이 이 앱의 핵심입니다. 키움증권 체결알림("[키움]체결통보 / 종목 / 매수1주 / 평균단가215,000원")이 카카오톡이나 문자로 오면 앱이 읽어 보유와 매매기록을 채웁니다. 취소·거부·주문접수 안내는 무시합니다. 처음엔 카카오톡 '키움증권 체결알림' 채팅방을 대화 내보내기 → [주식비서] 로 공유하면 과거 체결이 한꺼번에 들어오고, "발견 N건 · 반영 x · 코드 못 찾음 y · 이미 있음 z" 결과가 나옵니다. 같은 날·같은 구분·같은 수량·같은 단가는 한 번만 들어가니 여러 번 넣어도 안전합니다.

계좌 카드 — 장중 2초마다

매수금액 · 평가금액 · 예수금 · 보유자산 · 평가손익 · 수익률이 위에, 실현손익(당일·주간·월간·년간·누적)과 "▾ 추이" 누적 곡선, "연 예상 배당" 이 아래에 있습니다. 장중에는 머리말에 "· 실시간" 이 붙고 값이 2초마다 움직입니다.

보유 목록

행마다 세 줄입니다. 1줄 종목명·현재가·평가손익·수익률, 2줄 단가·수량·매입·평가·등락, 3줄 시총·PER·영업이익률·배당·예상배당. 오른쪽 미니차트 위 "자동/정리/3차" 배지는 엔진 관리 상태입니다. 기본 정렬은 수익률 순이고, 값은 계속 갱신되지만 순서는 탭을 열 때와 새로고침 때만 다시 매겨 행이 뛰어다니지 않습니다. "소액자산 숨기기"(기본 켜짐)로 5,000원 미만은 감춥니다. 엔진 미체결 주문이 있으면 "미체결 N건" 바가 나타납니다.

매매기록 원장(⋮)

종목별로 날짜 · 구분 · 수량 · 단가 · 보유(계산값) · 출처 표가 열립니다. 출처는 자동(엔진 체결, 잠김) / 파일(카카오톡) / 문자 / 수동 으로 구분됩니다. 위 요약줄에 "N주 · 평단 X · N차 · 실현손익" 이 계산되고, 보유보다 많이 판 줄이 있으면 저장이 막힙니다. 같은 창에서 목표가도 저장합니다.

종료거래(📦)

전량 매도로 끝난 매매가 모입니다. 합계(건수·종목수), 실현손익, 수익률, 승률, 이익/손실 건수가 위 카드에, 표에는 종목별 실현손익과 "N회차 · 기간 · 보유일 · 주수 · 체결 건수" 가 나옵니다.

매매리포트(📋)

보유 탭 수익률 셀, 종료거래 줄 끝, 종목 상세 📋 에서 엽니다. 종목·합계손익·수익률, 보유/평단/보유기간/연환산, 평단선과 매수▲·매도▼ 마커가 찍힌 차트, 매매내역 표가 한 장의 카드로 만들어집니다. 봉 칩(분봉 1~60분)과 두 손가락 확대로 원하는 구간을 잡고, "금액 가리기" 로 손익·수량을 ••• 로 바꾼 뒤 [이미지 복사] 나 [공유] 로 가족에게 보냅니다.

7. 알림 — 필요한 것만, 종목당 하루 한 번

모든 알림은 기본 꺼짐이고 원하는 것만 켭니다.

알림 언제 오나
시황 브리핑 오늘의 시황이 새로 발행되면 요약 첫 줄
목표가 돌파 저장한 목표가를 넘는 순간(위로 넘으면 매도 목표, 아래로 내려오면 매수 목표)
평단 돌파 평단을 아래로 깨면(손실 전환), 위로 올라오면(본전 회복)
관심/보유 신규 공시 관심·보유 종목에 새 공시가 올라오면
장중 실시간 감시 평일 09:00~15:30 에 1분마다 목표가·평단·급등락을 확인해 바로 알림
관심/보유 급등락 설정한 %(기본 ±5) 이상 움직이면
배당 알림 배당 기준일 임박(D-2)
공모주 청약 일정 청약 시작 임박(D-2)

기본 확인 주기는 약 30분이고, "장중 실시간 감시" 를 켜면 1분으로 촘촘해집니다. 가족 PC 에 엔진이 있으면 "자동매매 PC 응답 없음", "장중 로그인 끊김" 같은 PC 상태 알림도 옵니다.

8. 자동매매 연동 — 가족 PC 엔진과 한 몸

가족 PC 에 키움 자동매매 엔진을 설치하면 앱이 리모컨이 됩니다.

  • 설정 탭 › 키움 자동매매 설정: 엔진이 발행한 현재 설정을 읽어 온 뒤 바꾼 항목만 전송합니다. 자동매매 ON/OFF · 긴급정지 · 최대 보유종목수, ① 최초진입(종목당 매수금액), ② 분할매수(트리거 수익률·추가진입 비율·시총 티어별 최대 차수), ③ 분할매도(기본 목표·차수당 추가·수익반납률), ④ 최종청산(손절·빠른 트레일링). 전송 전 "실거래 설정 변경" 확인 창에 바뀐 항목이 나열됩니다.
  • 종목 상세 🛒 주문, 저장 검색의 자동 ON, 관심 그룹별 자동매매가 모두 이 엔진으로 갑니다.
  • 엔진이 보유 중인 종목은 검색·관심·보유 화면에 🟢/자동/정리 배지로 표시되고, 엔진이 받는 실시간 틱과 호가가 앱 화면에도 흘러옵니다.
  • 엔진이 없어도 앱의 나머지 기능은 전부 그대로 씁니다.

9. 앱이 스스로 새 버전을 받는다

앱을 열 때와 돌아올 때 새 버전을 확인하고, 있으면 "새 버전 v…" 팝업이 뜹니다. [지금 업데이트] 를 누르면 내려받기 → 설치 화면까지 이어지고 [설치] 만 누르면 됩니다. 스토어를 거치지 않으니 관리자가 고친 내용이 당일 폰에 들어옵니다. 설정 탭 첫 줄의 [최신 받기] 로 수동 확인도 됩니다.

10. 개인정보와 공유 범위

  • 이름·전화번호는 가족 전용 비공개 저장소와 관리자 앱에만 저장됩니다.
  • 관리자 앱의 "사용자 관리" 에는 구성원별 평가손익·실현손익·월별 실현손익·보유종목이 보입니다. 앱이 시세를 갱신할 때 5분에 1회, 값이 바뀐 때만 올라갑니다.
  • 관심 종목, 목표가, 알림 설정, 매매기록은 폰 안에만 있습니다. 앱을 지우면 함께 사라지니 주의하세요.

이런 분께

  • 증권사 앱 여러 개를 오가며 시황·검색·알림을 따로 보던 분.
  • 체결 내역을 엑셀에 손으로 옮기다 지친 분 — 카카오톡 체결알림만 켜 두면 됩니다.
  • 가족끼리 같은 종목 자료를 보고 이야기하고 싶은 분.
  • 집 PC 에 자동매매를 돌리면서 밖에서 설정을 만지고 싶은 분.

설치부터 화면별 조작까지는 사용 설명서에 있습니다. 앱 안에서는 설정 탭 → [사용 설명서] 로 언제든 엽니다.
